# Contributing to CraftCut

Thank you for your interest in contributing to **CraftCut**! 🎉

CraftCut is an open-source, clean-room reimplementation of CapCut Mobile, built with modern web technologies and native Android support, with **all PRO features completely free forever**.

---

## Code of Conduct

Please adhere to our [Code of Conduct](CODE_OF_CONDUCT.md) in all interactions.

---

## Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/CraftCut.git
   cd CraftCut/craftcut-app
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Verify production build:**
   ```bash
   npm run build
   ```

---

## Core Principles

1. **1:1 Visual & Tactile Fidelity:** Every button, timeline gesture, double-dot handle, modal, and color palette must match the authentic CapCut mobile feel.
2. **Zero Paywalls:** All advanced features (Auto Cutout, Auto Captions, Vocal Isolation, 4K Export, Optical Flow 60fps) must remain completely free and open.
3. **Open Standards:** Favor standard Web APIs (`Canvas`, `Web Audio API`, `MediaRecorder`, `WebRTC`, WebCodecs) and clean native Android integrations over proprietary closed blobs.
