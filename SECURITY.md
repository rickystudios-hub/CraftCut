# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

CraftCut takes the security of its users seriously. If you discover a vulnerability or security issue:

1. Please do **NOT** open a public issue.
2. Email the core maintainers or submit a private security advisory on GitHub.
3. We will acknowledge receipt within 48 hours and work with you on a patch and disclosure timeline.
